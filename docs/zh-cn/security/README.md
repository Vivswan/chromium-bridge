# 安全文档

深入的安全模型, 每个关注点一份文档。摘要与报告途径见 [SECURITY.md](../../../.github/SECURITY.md)。

| 文档 | 涵盖内容 |
|----------|----------------|
| [security-bar.md](./security-bar.md) | 一句话标准线、它所应对的攻击者、项目止步之处, 以及各操作系统的现状; 应首先阅读 |
| [threat-model.md](./threat-model.md) | 资产、对手、信任边界, 以及按边界列出的残余风险 |
| [trust-boundaries.md](./trust-boundaries.md) | 每一个进程边界及其强制执行机制 |
| [tool-risk-matrix.md](./tool-risk-matrix.md) | 每个工具的风险等级、它的门禁, 以及它所要求的确认 |
| [incident-response.md](./incident-response.md) | 怀疑某个边界被突破时该做什么, 以及修复如何发布 |
