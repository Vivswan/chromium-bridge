# 安全文件

深入說明安全模型, 每個關注點一份文件。摘要與回報途徑在 [SECURITY.md](../../../.github/SECURITY.md)。

| 文件 | 涵蓋內容 |
|----------|----------------|
| [security-bar.md](./security-bar.md) | 一句話說清標準線、它應對的攻擊者、專案止於何處, 以及各作業系統的狀態; 建議先讀這份 |
| [threat-model.md](./threat-model.md) | 資產、對手、信任邊界, 以及按邊界逐一列出的殘餘風險 |
| [trust-boundaries.md](./trust-boundaries.md) | 每一個程序邊界, 以及強制執行它的機制 |
| [tool-risk-matrix.md](./tool-risk-matrix.md) | 每個工具的風險等級、它的閘門, 以及它需要的確認 |
| [incident-response.md](./incident-response.md) | 懷疑某個邊界被突破時該做什麼, 以及修復如何發行 |
